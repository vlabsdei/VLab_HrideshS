### About the Experiment

This experiment explores the fundamental limits of parallel computing as described by Amdahl's Law. Students investigate how the parallelizable fraction of a workload, the number of computing nodes, and real-world communication overhead determine the theoretical speedup, the point of diminishing returns, and the wasted infrastructure expenditure when scaling GPU clusters.
