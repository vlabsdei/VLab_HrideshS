### About the Experiment

This experiment explores workload orchestration in shared GPU computing clusters. Students investigate how different scheduling algorithms (FIFO, SJF, Fair-Share), workload mixes, and preemption protocols (Kill/Restart vs Graceful Checkpointing) affect average job wait time, cluster utilization, and wasted compute resources. The experiment also demonstrates how high-priority emergency jobs trigger automated resource evictions.
