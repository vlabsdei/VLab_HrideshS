### About the Experiment

This experiment explores the performance characteristics of gradient synchronization in distributed AI training. Students investigate how gradient tensor size, network injection speed, and transfer protocol (TCP/IP vs RDMA) affect all-reduce synchronization latency, kernel copying overhead, and cluster compute efficiency. The experiment also demonstrates how a single straggler node can stall an entire distributed training cluster.
