### About the Experiment

This experiment explores the network latency characteristics of different high-performance computing interconnect topologies. Students investigate how network topology (Fat-Tree vs 3D Torus), cluster size, InfiniBand link standard (NDR vs XDR), and payload size affect worst-case routing hops, serialization latency, and total network fabric delay in large-scale GPU computing clusters.

The experiment demonstrates why Fat-Tree architectures are preferred for scale-out configurations despite their higher cabling requirements, and how 3D Torus routing scales with cluster dimensions.
