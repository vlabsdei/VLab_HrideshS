### About the Experiment

This experiment explores the memory requirements of deploying Large Language Models (LLMs) on GPU accelerators. Students investigate how model parameter count, quantization bit-width, context length, and batch size influence the total VRAM allocation, including static model weights and dynamic KV cache memory, and whether a given configuration can be successfully deployed or triggers a CUDA Out-of-Memory (OOM) crash.

The experiment provides an interactive simulation where students can configure LLM deployment parameters and observe real-time VRAM usage breakdowns. It demonstrates the critical trade-offs between model precision, context window size, and batch throughput that AI infrastructure engineers face when deploying production LLM systems.
