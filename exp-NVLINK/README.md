### About the Experiment

This experiment explores the performance characteristics of different GPU interconnect standards used in modern data centers and high-performance computing systems. Students investigate how batch tensor data size, interconnect bandwidth (PCIe Gen4, PCIe Gen5, NVLink), and GPU processing duration affect data transfer latency, total step iteration time, and GPU operational utilization.

The experiment demonstrates how I/O bottlenecks can cause expensive GPU silicon to remain idle for significant portions of each training step, and how high-bandwidth interconnects like NVLink overcome these limitations through mesh topology and direct memory fabric mapping.
